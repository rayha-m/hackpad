# hackpad

A 3-key macropad with a volume knob (rotary encoder) built with a Seeed XIAO RP2040, from the Hack Club Hackpad guide.

* Maintainer: [rayha-m](https://github.com/rayha-m)
* Hardware: Seeed XIAO RP2040, 3x MX switches, 3D-printed sandwich case

Build: `qmk compile -kb hackpad -km default`

Flash: hold the BOOT button on the XIAO while plugging it in, then drag the `.uf2` file onto the `RPI-RP2` drive.
